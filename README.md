# ClinPGx Database

A skill for accessing pharmacogenomics information from ClinPGx, including gene-drug relationships and clinical pharmacogenetics guidance.

## Capabilities

- Explore gene-drug interactions and pharmacogenomic annotations.
- Retrieve CPIC guideline information.
- Review allele function and phenotype data.
- Locate drug-label information and supporting evidence.
- Use the included reference material and script for supported database access.

## Usage

Use this skill for pharmacogenomics research, precision-medicine literature review, and structured retrieval of ClinPGx data. Follow the query and data-handling guidance in `SKILL.md` and the accompanying resources.

## Responsible interpretation

Database annotations and guidelines are evidence resources, not individualized prescribing instructions. Verify current guideline versions, allele interpretation, medication context, and patient-specific factors with qualified healthcare professionals before any clinical application.
